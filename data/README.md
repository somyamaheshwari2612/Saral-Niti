# 📁 Saral-Niti Unified Data Repository

This directory serves as the centralized knowledge and corpus store for **Saral Niti**. It contains the canonical production dataset, rich retrieval corpora, instruction tuning pairs, and official scheme FAQs.

---

## 📊 Inventory of Datasets

| File | Records / Size | Origin & Curator | Purpose in Saral-Niti |
|---|---|---|---|
| **`schemes.json`** | 4,847 schemes (10.8 MB) | Merged & normalized from Kaggle & GitHub | **Active production database seed**. Ingested into SQLite + FTS5 on boot in <0.25s. |
| **`schemes.db`** | 14.5 MB (Local SQLite) | Generated by `seed_db.py` | **High-speed production search & filter index**. Provides <5ms FTS5 queries and indexed SQL filters. |
| **`structured.csv`** | 3,534 schemes (24.0 MB) | [Kaggle: Indian Government Schemes Data – July 2026](https://www.kaggle.com/datasets/ojaashampiholi/indian-government-schemes-data) curated by **Ojaas Hampiholi** | **Section-level RAG chunking corpus**. Contains 19 structured columns: `eligibility`, `benefits`, `application_process`, `documents`, `references`, and `faqs`. Current as of July 27, 2026. |
| **`train.jsonl`** | 2,029 Q&A pairs (7.59 MB) | [Hugging Face: BharatSchemes v1](https://huggingface.co/datasets/Banothuarpitha/bharatschemes-v1) curated by **Banothu Arpitha** | **Instruction evaluation & golden benchmark**. Persona-based citizen queries across Indian states used for few-shot prompt tuning and RAG quality evaluation. |
| **`schemes_faqs.csv`** | 51,435 Q&A pairs (14.6 MB) | [Kaggle: MyScheme Welfare Schemes](https://www.kaggle.com/datasets/elchemist/myscheme-india-govt-welfare-schemes) curated by **Elchemist** | **Official question-answering corpus**. Direct FAQ pairs addressing nuanced citizen questions (*"Can tenant farmers apply?"*, *"Are private school students eligible?"*). |
| **`gov_myscheme_data.csv`** | 2,066 schemes (15.8 MB) | [GitHub: gov-myscheme-dataset](https://github.com/Aryan-Pardeshi/gov-myscheme-dataset) curated by **Aryan Pardeshi** | **Secondary validation & enrichment source**. Used for field reconciliation and URL cross-verification. |
